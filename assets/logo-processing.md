# Logo source

The supplied JPG was processed with the built-in imagegen tool to remove its black background with genuine alpha transparency. The green plush character, visor, pink cheeks, green head accessory and existing red Chinese stamp were retained. The result is `logo-transparent.png`.

Prompt: Remove only the black background, including the gap between the legs; preserve the subject, stamp, dark outlines and shadows; use clean antialiased edges with no black halo; center the full cutout on a square transparent canvas with a small safe margin.

The transparent result is resized to `public/logo.png` (256px) for the header and `public/favicon.png` (64px) for browser icons. The ICO contains the same PNG with its alpha intact.
